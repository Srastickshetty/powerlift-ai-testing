# U4 — Responsive rules & QA matrix
| Rule | 360 | 768 | 1280 |
|---|---|---|---|
| Nav | bottom tabs | bottom tabs/rail | left rail |
| Columns | 1 | 2 | 12-col + right panel |
| Tables | cards | table | table, sticky header |
| Modals | bottom sheet | centered | side panel/centered |
| Charts | 180 px | 240 px | 280–320 px |
Per-screen checklist: no horizontal scroll · targets ≥44 px · text ≥14 px (captions 12) · visible focus · landscape phone OK · iOS safe-area OK · keyboard never hides active input · 200% zoom OK · offline banner · dark/light OK.
Test widths: 375 (iPhone SE), 412 (Pixel), 768 (iPad), 1280 (laptop), 1920 (content capped at 1280).
